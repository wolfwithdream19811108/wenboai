ImageAI API 文档

创建图片

调用图片生成接口前，账号必须完成实名认证并年满18周岁；API Key 可在实名后的控制台创建。

POST /api/ai/imagegenerate/create_for_test

请求头：Authorization: Bearer wb_sk_xxx

请求示例

{
  "model": "jianyuan",
  "stream": false,
  "dialogue": [
    {"role": "user", "content": "一件青花瓷文创产品设计"}
  ]
}

返回参数

接口不论成功或失败均返回 HTTP 200；请使用 status_code 判断业务结果。既有字段继续保留，以兼容已经接入的调用方。

参数名称接口说明类型是否必选
reply回复内容；成功时为生成图片地址，失败时为对外错误提示string必选
status_code业务状态码；0 表示成功，非 0 表示失败integer必选
id通用唯一识别码，用于请求及生成内容溯源；与 request_id 一致string可选
content兼容字段；非流式成功结果中的图片地址string必选
choices兼容字段；流式结果数组，非流式请求为空字符串array|string必选
status兼容字段；success 或 failedstring必选
reason兼容字段；成功时为 success，失败时为错误提示string必选
request_id请求唯一识别码，用于查询和排障string可选

成功响应示例

{
  "reply": "https://example.com/generated/image.png",
  "status_code": 0,
  "id": "4c98f30b64844c87a01df2fb805b27a1",
  "content": "https://example.com/generated/image.png",
  "choices": "",
  "status": "success",
  "reason": "success",
  "request_id": "4c98f30b64844c87a01df2fb805b27a1"
}

失败响应示例

{
  "reply": "鉴权失败：API_KEY无效",
  "status_code": 40101,
  "id": "c991ba7525df4a0aa667bc378e13c65a",
  "content": "",
  "choices": "",
  "status": "failed",
  "reason": "鉴权失败：API_KEY无效",
  "request_id": "c991ba7525df4a0aa667bc378e13c65a"
}

业务错误码

不同业务状态码会返回对应的具体 reply，不会统一成同一句错误提示。仅内容分类判定相关的拒绝或不可用，按后台配置返回统一的文博领域拒答。

status_code说明
0请求成功
40001请求方法、JSON 格式或请求参数错误
40101Bearer Key 缺失、无效或已失效
40201账号积分不足
40301账号状态、实名认证、年龄、功能权限或内容范围校验未通过
42901请求频率超过限制
50001图片生成、分类、配置、存储或其他服务异常
50401图片生成超时

测试分类而不生成

{
  "model": "jianyuan",
  "dry_run": true,
  "dialogue": [{"role":"user","content":"测试提示词"}]
}

dry_run=true 时仍使用上述统一返回字段，并在 data 中返回分类测试结果；不会调用真实图片生成服务。

生成成功会扣除积分并写入作品记录；失败会自动退回预扣积分。
